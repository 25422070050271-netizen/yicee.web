# YICEE.WEB

Ecosistema web de **Los YICEE®**.

## Estructura

- `/` — página principal de YICEE.WEB
- `/apps/core/` — YICEE CORE v2
- `/apps/nexus/` — YICEE NEXUS / NEXUS Control Center
- `/apps/los-yicee/` — página de presentación de Los YICEE®
- `/lab/` — laboratorio de prototipos y experimentos
- `/assets/` — recursos compartidos

## Apps integradas

### YICEE CORE v2
Centro base del ecosistema YICEE.

### YICEE NEXUS
Centro de control futurista para dispositivos, automatización, gaming y media, importado del repositorio `25422070050271-netizen/-nexus`.
